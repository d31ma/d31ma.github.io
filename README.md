# d31ma.github.io

This site only serves the link verification files for Tachyon's link test apps:

- `/.well-known/apple-app-site-association` (iOS / macOS universal links)
- `/.well-known/assetlinks.json` (Android app links)
- `/.well-known/windows-app-web-link` (Windows app URI handlers)

The files are generated by `scripts/native/verified-links-files.mjs` in [d31ma/Tachyon](https://github.com/d31ma/Tachyon).
